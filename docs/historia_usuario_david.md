# Historia de Usuario Gestion de Bibliotecas - 01

| Campo | Descripción |
|---|---|
| **Título** | Registro de préstamos de libros |
| **Como** | Bibliotecario del sistema |
| **Quiero** | Registrar el préstamo de libros a los usuarios |
| **Para** | Llevar un control organizado de los ejemplares prestados y sus fechas de devolución |
| **Prioridad** | Alta |
| **Estado** | Finalizado |

## Criterios de aceptación

| ID | Criterio |
|---|---|
| CA-01 | El sistema debe permitir seleccionar un usuario registrado |
| CA-02 | El sistema debe permitir seleccionar un libro disponible |
| CA-03 | El sistema debe registrar la fecha del préstamo |
| CA-04 | El sistema debe generar automáticamente la fecha de devolución |
| CA-05 | El libro prestado debe cambiar su estado a “No disponible” |
| CA-06 | El sistema debe mostrar un mensaje de confirmación al finalizar el registro |
